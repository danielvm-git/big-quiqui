    • Reuse the existing hero rig (18 poses), about 30 item images and 35 audio files, renamed to English ids.
    • About 6 accessories and 9 foods already exist. Add voice lines for each need.
  • ProgressionEach completed care step credits stars and coins. A full day unlocks the prize wheel.
  • Risks
    • The need timer can feel like pressure. It only changes the bubble, never ends a step.
    • This is the game that extracts the core, so the core interface must be stable before it starts.
