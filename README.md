# QuiQui

An ad-free, offline game line for children aged 4 to 7, built with Godot 4.7. One shared core, nine small games.

Each game lives in its own repository and is cloned into this folder (it is git-ignored here).

| Game | Repository |
|---|---|
| Cleanup | [big-quiqui-cleanup](https://github.com/danielvm-git/big-quiqui-cleanup) |
| Adventure, Care, Dance, Flusier, Kitchen, Salon, Story, Town | planned: see `big-quiqui-*/specs/product/GAME_PLAN.html` |

The earlier attempt is kept as [big-quiqui-old](https://github.com/danielvm-git/big-quiqui-old) (private).
